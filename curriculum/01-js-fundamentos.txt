@@lesson js-primeiro-programa | Seu primeiro programa | 10
@@body
Programar é escrever instruções **precisas** para o computador executar, uma depois da outra. Ele é rápido, mas literal: faz exatamente o que você escreveu, não o que você quis dizer. Aprender a programar é, em boa parte, aprender a ser exato.

JavaScript (JS) é a linguagem da web. Roda em todo navegador e, com o Node.js, também em servidores. É o que dá vida a páginas, aplicativos e APIs.

### Mostrando algo na tela

A instrução mais usada para aprender é `console.log(...)`. Ela escreve um valor no **console**, a área de saída logo abaixo do editor.

```js run
console.log("Olá, mundo!");
console.log(2 + 3);
```

Textos ficam entre aspas e se chamam **strings**. Números não levam aspas. Cada instrução termina com `;`.

### Guardando valores

Uma **constante** guarda um valor sob um nome, para você usá-lo depois:

```js run
const cidade = "Curitiba";
console.log(cidade);
```

Tudo que vem depois de `//` é **comentário**: o computador ignora, serve para explicar o código para humanos.

> **Dica:** clique em "▶ rodar" nos exemplos e depois mude o código. Quebrar e consertar é a melhor forma de aprender.

console.log(mensagem);

@@lesson js-variaveis-tipos | Variáveis e tipos de dados | 15
@@body
Variáveis são **caixas com nome**. Você guarda um valor, e o nome permite recuperá-lo depois.

### `const`, `let` e `var`

- `const`: o nome não pode ser reatribuído. É a escolha padrão.
- `let`: o valor pode mudar ao longo do programa.
- `var`: a forma antiga. Existe em códigos antigos, mas evite.

```js run
const nome = "Ana";
let pontos = 10;
pontos = pontos + 5;
console.log(nome, pontos);
// nome = "Bia";  // erro: Assignment to constant variable.
```

Nomes usam `camelCase` (`precoFinal`), não têm espaços, não começam com número e diferenciam maiúsculas de minúsculas (`idade` e `Idade` são nomes diferentes).

### Tipos primitivos

| Tipo | Exemplo | Para que serve |
| --- | --- | --- |
| `string` | `"texto"` | Texto |
| `number` | `42`, `3.14` | Inteiros e decimais |
| `boolean` | `true`, `false` | Verdadeiro ou falso |
| `null` | `null` | Ausência **intencional** de valor |
| `undefined` | `undefined` | Ainda não tem valor |
| `bigint` | `123n` | Inteiros gigantes |

O operador `typeof` informa o tipo de um valor:

```js run
console.log(typeof "oi");
console.log(typeof 7);
console.log(typeof true);
console.log(typeof undefined);
console.log(typeof null); // "object" é um bug histórico da linguagem
console.log(0.1 + 0.2);   // 0.30000000000000004
```

> **Atenção:** números decimais usam ponto flutuante, por isso `0.1 + 0.2` não dá exatamente `0.3`. Para dinheiro, guarde centavos como inteiros.

@@lesson js-operadores | Operadores e expressões | 15
@@body
Uma **expressão** é qualquer trecho que produz um valor: `2 + 3`, `idade >= 18`, `nome.length`.

### Aritméticos

`+` `-` `*` `/` e também `%` (resto da divisão) e `**` (potência). O `%` é muito útil: `n % 2 === 0` significa "n é par".

```js run
console.log(17 / 5);
console.log(17 % 5);
console.log(2 ** 10);
console.log(Math.floor(17 / 5)); // só a parte inteira
```

### Atribuição composta

`x += 1` é o mesmo que `x = x + 1`. Existem `-=`, `*=`, `/=` e os atalhos `x++` e `x--`.

### Comparação

Use sempre `===` e `!==` (igualdade estrita). Os operadores `==` e `!=` convertem tipos escondido e geram surpresas: `0 == ""` é `true`. Os demais são `<`, `<=`, `>`, `>=`.

### Lógicos

- `&&` (E): verdadeiro se **os dois** lados forem.
- `||` (OU): verdadeiro se **pelo menos um** for.
- `!` (NÃO): inverte.
- `??` (coalescência nula): usa o valor da direita só quando o da esquerda é `null` ou `undefined`.

```js run
const idade = 20;
const temCarteira = true;
console.log(idade >= 18 && temCarteira);
const apelido = null;
console.log(apelido ?? "sem apelido");
```

Quando misturar vários operadores, use parênteses para deixar a intenção clara.

@@lesson js-strings | Textos (strings) | 15
@@body
Strings guardam texto. Podem usar aspas simples, duplas ou crases. As crases criam **template literals**, onde `${...}` insere valores no meio do texto:

```js run
const nome = "Lia";
const idade = 30;
console.log(`${nome} tem ${idade} anos e ${idade + 1} no ano que vem.`);
```

### Posições começam em zero

```js run
const palavra = "JavaScript";
console.log(palavra.length);   // 10
console.log(palavra[0]);       // "J"
console.log(palavra.at(-1));   // "t" (último)
```

### Métodos que você vai usar sempre

| Método | O que faz |
| --- | --- |
| `trim()` | Remove espaços do começo e do fim |
| `toUpperCase()` / `toLowerCase()` | Muda a caixa |
| `includes("x")` | Contém o trecho? |
| `startsWith("x")` / `endsWith("x")` | Começa/termina com? |
| `slice(i, j)` | Recorta do índice `i` até antes de `j` |
| `split(" ")` | Quebra em um **array** de pedaços |
| `replaceAll("a", "b")` | Troca todas as ocorrências |
| `padStart(5, "0")` | Completa à esquerda |

```js run
const frase = "  aprender é divertido  ";
console.log(frase.trim().toUpperCase());
console.log("a,b,c".split(","));
console.log("7".padStart(3, "0"));
```

@@lesson js-funcoes | Funções | 20
@@body
Uma **função** é um bloco de código com nome que você pode executar quantas vezes quiser. Pense numa máquina: recebe **entradas** (parâmetros), faz algo e devolve uma **saída** (retorno).

```js run
function dobro(numero) {
  return numero * 2;
}

console.log(dobro(4));
console.log(dobro(10));
```

- `numero` é um **parâmetro**: o nome que a função dá à entrada.
- `4` e `10` são **argumentos**: os valores reais passados na chamada.
- `return` devolve o resultado e **encerra** a função. Sem `return`, ela devolve `undefined`.

### Valores padrão

```js run
function saudar(nome, saudacao = "Olá") {
  return `${saudacao}, ${nome}!`;
}
console.log(saudar("Rui"));
console.log(saudar("Rui", "Oi"));
```

- Dê nomes que são **verbos**: `calcularTotal`, `ehPar`, `buscarUsuario`.
- Faça cada função fazer **uma coisa só**.
- Prefira devolver (`return`) a imprimir (`console.log`) dentro da função. Quem devolve pode ser testado e reutilizado.

> **Nota:** funções de teste aqui devolvem valores. É isso que a verificação confere.

@@module js-fluxo | js | Controle de fluxo | Decisões e repetição: o que faz um programa parecer inteligente.

@@lesson js-condicionais | Tomando decisões | 20
@@body
Programas precisam escolher caminhos. A estrutura básica é o `if`:

```js run
const nota = 6;

if (nota >= 7) {
  console.log("aprovado");
} else if (nota >= 5) {
  console.log("recuperação");
} else {
  console.log("reprovado");
}
```

O computador testa as condições **de cima para baixo** e executa só o primeiro bloco verdadeiro.

### Verdadeiro e falso ("truthy" e "falsy")

Em condições, JS converte qualquer valor para booleano. Os únicos valores **falsy** são: `false`, `0`, `""`, `null`, `undefined`, `NaN` (e `0n`). Todo o resto é truthy, inclusive `"0"`, `[]` e `{}`.

### Ternário e `switch`

```js run
const idade = 20;
console.log(idade >= 18 ? "adulto" : "menor");

const dia = 3;
switch (dia) {
  case 1:
    console.log("domingo");
    break;
  case 3:
    console.log("terça");
    break;
  default:
    console.log("outro");
}
```

Sem `break`, o `switch` "cai" para o próximo caso. Em funções, é comum usar `return` direto em cada caso.

### Retorno antecipado

Trate os casos inválidos primeiro e devolva logo. Isso evita `if` dentro de `if` e deixa o código plano:

```js
function dividir(a, b) {
  if (b === 0) return null;
  return a / b;
}
```

}

$t('classificarNota(5.5) = "recuperação"', () => $eq(classificarNota(5.5), 'recuperação'));
$t('classificarNota(2) = "reprovado"', () => $eq(classificarNota(2), 'reprovado'));

function ehBissexto(ano) {

    case 5: return "quinta";
    case 6: return "sexta";
    case 7: return "sábado";
    default: return "inválido";

}

@@lesson js-lacos | Repetição com laços | 20
@@body
Quando uma tarefa se repete, você não copia o código: usa um **laço** (loop).

### `for`

Três partes: início; condição para continuar; passo a cada volta.

```js run
for (let i = 1; i <= 5; i++) {
  console.log("volta", i);
}
```

### `while`

Repete enquanto a condição for verdadeira. Use quando não se sabe quantas voltas serão.

```js run
let n = 100;
let passos = 0;
while (n > 1) {
  n = n / 2;
  passos++;
}
console.log(passos);
```

> **Cuidado:** se a condição nunca ficar falsa, você cria um **laço infinito** e o programa trava. O editor interrompe a execução depois de alguns segundos.

### `for...of`

Percorre os itens de um array ou de um texto, sem se preocupar com índices:

```js run
for (const letra of "JS") {
  console.log(letra);
}
```

### Acumuladores

O padrão mais comum: uma variável começa em um valor neutro e vai sendo atualizada.

```js run
let soma = 0;
for (let i = 1; i <= 4; i++) {
  soma += i;
}
console.log(soma); // 10
```

@@module js-colecoes | js | Coleções e dados | Arrays, objetos, callbacks e as ferramentas do dia a dia de quem programa.

@@lesson js-arrays | Arrays (listas) | 20
@@body
Um **array** é uma lista ordenada de valores. Índices começam em 0.

```js run
const frutas = ["maçã", "banana", "uva"];
console.log(frutas[0]);
console.log(frutas.length);
console.log(frutas.at(-1)); // último
frutas.push("pera");        // adiciona no fim
console.log(frutas);
```

### Operações principais

| Método | Efeito | Muda o original? |
| --- | --- | --- |
| `push(x)` / `pop()` | Adiciona / remove no **fim** | Sim |
| `unshift(x)` / `shift()` | Adiciona / remove no **início** | Sim |
| `includes(x)` / `indexOf(x)` | Procura um valor | Não |
| `slice(i, j)` | Copia um trecho | Não |
| `splice(i, n)` | Remove (ou insere) no meio | Sim |
| `join(", ")` | Junta em um texto | Não |
| `reverse()` | Inverte | **Sim** |

### Copiar com spread

`[...lista]` cria uma **cópia rasa**. Fazer `const b = a` não copia nada: as duas variáveis apontam para a **mesma** lista.

```js run

const b = a;       // mesma lista
const c = [...a];  // cópia
b.push(4);
console.log(a, c);
```

@@lesson js-arrow-callbacks | Funções como valores | 20
@@body
Em JS, funções são **valores** comuns: podem ser guardadas em variáveis, passadas como argumento e devolvidas por outras funções. Uma função que recebe outra como argumento é um **callback**.

### Arrow functions

Uma sintaxe mais curta:

```js run
const dobro = (n) => n * 2;          // retorno implícito
const soma = (a, b) => {             // com bloco precisa de return
  return a + b;
};
console.log(dobro(5), soma(2, 3));
```

Com um único parâmetro, os parênteses são opcionais (`n => n * 2`). Para devolver um objeto literal em uma linha, coloque entre parênteses: `() => ({ ok: true })`.

### Callbacks

```js run
function repetir(vezes, acao) {
  for (let i = 0; i < vezes; i++) {
    acao(i);
  }
}

repetir(3, (i) => console.log("passo", i));
[10, 20].forEach((valor) => console.log(valor));
```

@@lesson js-arrays-funcionais | map, filter e reduce | 25
@@body
Os métodos de array que recebem callbacks substituem a maior parte dos laços `for` e deixam o código mais declarativo ("o que" em vez de "como").

| Método | Devolve | Uso |
| --- | --- | --- |
| `map(fn)` | Novo array do mesmo tamanho | Transformar cada item |
| `filter(fn)` | Novo array menor ou igual | Manter só os itens que passam no teste |
| `find(fn)` | Um item ou `undefined` | Achar o primeiro que passa |
| `some(fn)` / `every(fn)` | boolean | Algum / todos passam? |
| `reduce(fn, inicial)` | Um único valor | Acumular tudo em um resultado |
| `sort(cmp)` | O próprio array ordenado | Ordenar (**muda o original**) |

```js run

console.log(precos.filter(p => p >= 10));
console.log(precos.find(p => p > 20));
console.log(precos.some(p => p > 30), precos.every(p => p > 30));
console.log(precos.reduce((total, p) => total + p, 0));
```

@@lesson js-desestruturacao | Desestruturação, spread e rest | 20
@@body
Três recursos modernos que você verá em praticamente todo código JS atual.

### Desestruturação

Extrai valores de arrays e objetos para variáveis:

```js run
const [primeiro, segundo] = ["a", "b", "c"];
```

Também funciona nos parâmetros de uma função: `function exibir({ nome, preco })`.

```js run
const { a, ...resto } = { a: 1, b: 2, c: 3 };
```
